# AI Prototype Sandbox

A localized sandbox environment for prototyping structures, payloads, and configuration settings for open-source Large Language Models (LLMs).

## Features
- **Configurable Environment:** Centralized management for parameters like timeouts and model flags.
- **Payload Testing:** Simulated API call architecture to validate JSON structures before sending requests to external endpoints.

## Getting Started

### Installation
Clone the repository and install dependencies (if any):
```bash
git clone https://github.com
cd ai-prototype-sandbox
```

### Running the Sandbox
Execute the main script to see the mock payload handling in action:
```bash
python main.py
```
